# 照片备份对比 / 补齐工具（双向）

把「主盘」和「备份盘」逐项对比，找出**两边各自缺了什么**，再按原来的目录结构和文件名**双向补齐**。

- **正向**：源盘有、备份盘没有 → 复制到备份盘（补备份）
- **反向**：备份盘有、源盘没有 → 复制回源盘（补主盘）

> 源盘、备份盘都支持多选：多个源盘合并成一份「主库（并集）」参与比对；多个备份盘可勾选「合并池」。

## 功能特性

- **七类比对结果**：缺失 / 一致 / 大小不一致 / 内容不同 / 备份盘多余 / 同内容异路径 / 源盘内部重复
- **网页操作界面**：本地服务（端口 8765），支持「预演」——先只统计要复制多少个、多大，确认后再真复制
- **开机自启**：可设为 Windows 开机后台静默运行（无窗口）
- **安全设计**：全程只做复制、**从不删除**；先写 `.part_tmp` 临时文件再改名；复制前检查目标盘剩余空间；MD5 深度校验可选
- 照片（JPG/PNG/HEIC/RAW 等）和视频（MP4/MOV/MKV/AVI 等）一起比对，视频只比大小和 MD5 不做解码

## 下载与运行

### 方式一：完整运行包（推荐，开箱即用）

到本仓库的 **Releases** 页面下载 `photo-backup-compare.zip`，解压后：

1. 双击 `启动.bat`（或 `run.bat`）启动后台服务，**黑窗口别关**（可最小化）
2. 浏览器打开 http://127.0.0.1:8765/ 即可使用
3. 想开机自启就双击 `装开机自启.bat`；不想自启了双击 `卸载开机自启.bat`；`检查状态.bat` 查看服务是否在跑

> 完整包自带 Python 运行环境（官方嵌入式版），换到别的电脑也能直接跑。

### 方式二：仅源码（自备 Python 3.13）

```bash
git clone https://github.com/gaoyan1984/photo-backup-compare.git
cd photo-backup-compare
python app.py
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `app.py` | 后台服务 + 任务调度（HTTP 服务，端口 8765） |
| `engine.py` | 核心引擎：扫描、比对、双向复制、报告 |
| `index.html` | 操作界面（网页） |
| `install_autostart.py` | 开机自启安装 / 卸载 / 状态查询 |
| `selftest.py` | 引擎自测（在临时目录模拟，无需真实硬盘） |
| `e2e_test.py` | 端到端联调（需先启动服务） |
| `run.bat` / `install_autostart.bat` / `uninstall_autostart.bat` / `status.bat` | 英文启停脚本（仓库版为 ASCII，避免中文批处理乱码） |
| `使用说明.md` | 中文详细图文说明 |
